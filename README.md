# Summit SOC Detection Lab

This project is based on the TryHackMe Summit challenge.

The objective was to simulate a SOC analyst's role in detecting and preventing malware execution using the Pyramid of Pain framework.

Skills Demonstrated:

- Threat Detection Engineering
- IOC Analysis
- Malware Hash Analysis
- DNS Blocking
- Firewall Rule Creation
- Sigma Rule Development
- MITRE ATT&CK Mapping
- Incident Response
